# 記事公開処理

- **目的:** 公開Run一覧で選んだ状態に対応する応答だけが表示されることを確認する。
- **画面:** /admin/publication-runs/
- **起動:** npm run agent:verify -- run publication
- **Fixture:** admin-publication-runs.spec.tsが状態別の公開Run一覧を応答し、選択前に開始した応答を保留・解放する。
- **操作:** 公開済み状態を選び、応答が保留された間に失敗状態へ切り替え、最新状態を読み込む。最後に古い応答を解放する。
- **成功条件:** 一覧は失敗状態のタイトルを維持し、後から返った古い公開済み結果で上書きされない。
- **失敗条件:** 古い応答が最新選択を上書きする、読み込みが終わらない、実際のGitHub APIに接続する。
- **状態検査:** DOM上の状態・記事名と、Fixtureに記録したリクエスト順を照合する。GitHubや記事公開状態は変更しない。
- **証拠:** JSONレポート、Console Error添付、外部origin遮断一覧。失敗時はスクリーンショットとTrace。
- **再現テスト:** tests/e2e/admin-publication-runs.spec.ts の「公開処理一覧には最後に選択した状態の応答だけを反映する」。
