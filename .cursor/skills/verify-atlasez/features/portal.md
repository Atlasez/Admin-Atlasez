# ポータル

- **目的:** 参加中・運営中のプロジェクト、担当タスク、通知の入口を確認する。
- **画面:** /admin/portal/
- **起動:** npm run agent:verify -- run portal
- **Fixture:** admin-nav-portal.spec.ts のmockAdminShellが認証状態、ポータル、通知、プロフィールのAPIをブラウザ内で代替する。参加者と運営者の両方のプロジェクトを返す。
- **操作:** ポータルを開き、運営プロジェクトと参加者プロジェクトの見出し・項目・リンクを確認する。
- **成功条件:** 両区分がそれぞれ表示され、項目を選ぶとプロジェクト画面に移動できる。
- **失敗条件:** どちらかの区分が誤った側に表示される、Fixture以外の認証を求める、画面が読み込み中のままになる。
- **状態検査:** Playwright locatorでプロジェクト名と所属区分を照合する。APIはFixtureで完結するため永続状態は変更しない。
- **証拠:** JSONテストレポート、Console Error添付、外部origin遮断一覧。失敗時はスクリーンショットとTrace。
- **再現テスト:** tests/e2e/admin-nav-portal.spec.ts の「参加中のプロジェクトを運営と参加者に分けて表示する」。
