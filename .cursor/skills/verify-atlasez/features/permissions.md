# 権限管理

- **目的:** ユーザーごとの閲覧・編集・承認範囲を誤りなく表示する。
- **画面:** /admin/permissions/
- **起動:** npm run agent:verify -- run permissions
- **Fixture:** admin-permissions.spec.tsが権限APIをローカルで応答し、ユーザー、プロジェクト、分野、操作権限を固定する。
- **操作:** 権限管理を開き、対象ユーザーを選んで実効権限プレビューを確認する。
- **成功条件:** Fixtureで与えた閲覧・編集・承認範囲が各項目に表示される。
- **失敗条件:** 他ユーザー・別プロジェクトの権限が混ざる、編集範囲と承認範囲が混同される、予期しない永続化が起きる。
- **状態検査:** ユーザー別scopeと画面上の権限説明を照合する。保存操作はこのJourneyでは実行しない。
- **証拠:** JSONレポート、Console Error添付、外部origin遮断一覧。失敗時はスクリーンショットとTrace。
- **再現テスト:** tests/e2e/admin-permissions.spec.ts の「実効権限プレビューはユーザー単位の閲覧・編集・承認範囲を表示する」。
